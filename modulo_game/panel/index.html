Cómo jugar

Mano izquierda

  • Índice a la derecha → avanza
  • Índice a la izquierda → retrocede
  • Solo meñique → arriba / acción extra
  • Puño → moneda + START

Mano derecha

  • Palma abierta → disparo / golpe (ráfaga)
  • Puño → salto / patada
  • Índice hacia abajo → agacharse

Teclado

  • Flechas → mover
  • Z X C V → botones A B C D
  • Enter → START · 5 moneda
  • Espacio pausa · M sonido · F completa

Consejo: ponte a un brazo de la cámara, con luz de frente y las dos manos dentro del recuadro.
