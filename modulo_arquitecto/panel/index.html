Controles Arquitecto 3D

Camara (2 manos)

  • Pinza izquierda (pulgar+indice) → siguiente modulo en orden
  • Mano izq abierta → previsualiza el proximo
  • Indice derecho girando → rotar modulo
  • Palma derecha ←→ → mover en horizontal (X)
  • Palma derecha ↑↓ → subir / bajar
  • V derecha → duplicar
  • 2 pinzas → escalar + rotar
  • 2 palmas → orbitar escena

Mouse y teclado

  • Clic + arrastrar modulo
  • Flechas mover · Shift+flechas altura
  • R / Q rotar · + / - escalar
  • G alinear · Tab cambiar modulo
  • Ctrl+D duplicar · Supr eliminar
  • Ctrl+Z deshacer · Ctrl+S guardar
  • 1-4 herramientas · V / P / F / L vistas
