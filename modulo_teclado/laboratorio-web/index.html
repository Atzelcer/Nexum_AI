El guante no aparece / no hay COM
  1. Conecta el guante a esta PC con el cable USB. Arriba debe verse un puerto tipo COM3.
  2. Si el driver ya esta instalado pero no hay COM: casi siempre VirtualBox capturo el USB. En la VM: Dispositivos → USB y desmarca el CP210x (NEXUM intenta liberarlo solo).
  3. Solo si es la primera vez en este PC, instala el driver CP210x (Silicon Labs) o CH340.
  4. Cierra el Monitor Serie de Arduino si esta abierto (bloquea el COM).
  5. Sin cable: si el guante emite NEXUM-GUANTE (clave nexum1234), conecta esta PC a esa red, configura y vuelve a tu WiFi.
